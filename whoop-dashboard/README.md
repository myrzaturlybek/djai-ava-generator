# WHOOP Data Visualizer

Интерактивный дашборд, который визуализирует **все** данные из экспорта WHOOP:
восстановление, сон, нагрузку, тренировки и дневник привычек.

## Что внутри

Статический сайт без сборки — открывается прямо в браузере. Все данные
обрабатываются локально, ничего не отправляется на сервер.

| Файл | Назначение |
|------|-----------|
| `index.html` | разметка дашборда |
| `styles.css` | тема (тёмная/светлая) на основе валидированной палитры |
| `app.js` | построение всех графиков (Chart.js) |
| `data.js` | данные, сгенерированные из CSV-экспорта WHOOP |
| `chart.umd.js` | локальная копия Chart.js 4 (без CDN) |

## Разделы

- **Обзор** — ключевые показатели и главные графики.
- **Восстановление** — Recovery %, зоны, HRV, пульс покоя, температура кожи, SpO₂,
  частота дыхания, связь нагрузки/HRV с восстановлением.
- **Сон** — стадии сна по ночам, performance/efficiency/consistency, потребность и
  долг сна, состав сна, частота дыхания, время отхода ко сну.
- **Нагрузка и тренировки** — Day Strain, калории, тренировки по типам, нагрузка по
  каждой тренировке, зоны пульса, средний/максимальный пульс.
- **Привычки (журнал)** — доля ответов «Да» и их влияние на восстановление.

## Обновление данных

Положите новые CSV из WHOOP в папку `whoop/` рядом с `parse.js` и запустите:

```
node parse.js
```

Это перезапишет `data.js`. Затем задеплойте папку `whoop-dashboard` на Netlify.

## Деплой на Netlify

Каталог публикации — `whoop-dashboard` (см. `netlify.toml` в корне репозитория).
Сборка не требуется.
